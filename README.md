# 올리브영 선케어 제품 리뷰 데이터 분석

## 📋 프로젝트 개요

올리브영의 선케어 제품 카테고리별 리뷰 데이터를 분석하여 차년도 신규 선케어 제품 개발 아이디어를 도출하고 각 카테고리별 최적의 마케팅 방법을 분석한 프로젝트입니다.

- **프로젝트 기간**: 2024.08.05 ~ 2024.08.20 (2주)
- **개발 환경**: Python, Jupyter Lab, Streamlit
- **데모 서비스**: [Get your Suncare product](https://oliveyoungsunappuct-uat8fs4t3cmcdxqsutvwpv.streamlit.app/)

## 🛠 데이터 수집 및 전처리

### 데이터 수집
1. **1차 크롤링**: 
  - 선케어 카테고리(선크림, 선쿠션, 선스틱, 선스프레이, 선패치) URL에서 제품 정보 수집
  - 수집 정보: 제품명, 브랜드, 상세페이지 URL, 이미지 URL

2. **2차 크롤링**:
  - 상세페이지 URL을 통해 상품 후기 데이터 수집
  - 수집 정보: 별점, 피부타입, 리뷰 텍스트

### 데이터 전처리
- 정규 표현식을 활용한 이모티콘 제거
- Komoran 형태소 분석기를 활용한 토큰화
- 화장품 도메인 관련 사용자 사전 구축 및 적용
- 불용어 리스트 작성 및 텍스트 정제

## 📊 분석 내용

### 1. EDA (Exploratory Data Analysis)

#### 카테고리별 제품 및 리뷰 수
- 제품 수: 선크림(372개) > 선스틱 > 선쿠션 > 선패치 > 선스프레이(8개)
- 리뷰 수: 제품 수와 비례하여 동일한 순서

#### 카테고리별 주요 키워드 분석
텍스트 마이닝 기법을 활용하여 카테고리별 주요 키워드를 분석했습니다:

1. **워드클라우드 분석**: 리뷰 텍스트에서 가장 빈번하게 등장하는 키워드를 시각화
2. **TF-IDF 분석**: 카테고리별 특징적인 키워드 도출
  - 특정 카테고리에서 자주 등장하면서 다른 카테고리에서는 덜 등장하는 단어를 파악
  - 카테고리의 고유한 특성을 나타내는 키워드 식별

분석 결과, 각 카테고리별 주요 키워드는 다음과 같습니다:

- **선크림**: 촉촉, 톤업, 발림성
- **선쿠션**: 톤업, 퍼프, 촉촉
- **선스틱**: 보송, 뽀송, 휴대, 간편
- **선패치**: 골프, 기미, 운동
- **선스프레이**: 간편, 분사력, 몸

### 2. 마케팅 전략 분석

#### 콜라보레이션 효과
- **선크림 & 선쿠션**: 
 - 캐릭터 콜라보 제품 만족도가 가장 높음
 - 인플루언서 마케팅은 비추천

- **선스틱**: 
 - 인플루언서 콜라보 제품 만족도가 가장 높음
 - 캐릭터 콜라보는 비추천

- **선패치**: 
 - 인플루언서 마케팅이 판매순위에 긍정적 영향
 - 만족도 측면에서는 유의미한 차이 없음

- **선스프레이**: 
 - 콜라보 제품 부재로 분석 제외
